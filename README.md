# TesseraPoint IT — Independent Concept Project

A fictional US managed-services website created as a transparent portfolio concept. It is not commissioned by, affiliated with, or endorsed by a real company.

## Vercel deployment

Import this folder as a new Vercel project, choose **Other** as the framework preset, and keep `dist` as the output directory. No build command is required.

## Project structure

- `dist/index.html` — redesigned MSP website
- `dist/assessment/index.html` — interactive IT Resilience Check
- `dist/case-study/index.html` — transparent case-study page
- `dist/legacy/index.html` — fictional “before” website
- `dist/assets/` — shared styles and scripts

All forms and contact details are demonstrative and do not transmit data.
